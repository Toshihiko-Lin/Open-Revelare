OpenRevelare — Third-Party Notices
================================

This file lists the third-party components redistributed with OpenRevelare
(C# / .NET 8 build), along with their licenses and required attribution.

All native libraries are loaded dynamically and are shipped unmodified.
Where a component is licensed under the LGPL, users may replace it with a
compatible (including modified) version by substituting the corresponding
file in the installation directory.

Platform note: the exact set of native libraries differs per platform —
Windows ships raw_r.dll, Linux libraw_r.so.23, macOS libraw.23.dylib
(built from LibRaw 0.21.4 source, see packaging/macos/bundle-libraw.sh).

ACKNOWLEDGEMENTS (no code incorporated)

  LightSourceDecouple — Toshihiko-Lin, karasuyasabou (MIT)
    https://github.com/karasuyasabou/LightSourceDecouple
    The narrow-band RGB decoupling approach (Path A) originates here.

  DiVERE — flipswitchingmonkey (MIT)
    https://github.com/flipswitchingmonkey/DiVERE
    Reference for the density-domain colour model.

  darktable "negadoctor" module — Philippe Fremy and darktable contributors
    darktable is distributed under GPL-3.0. OpenRevelare references only the
    mathematical model (D_corr = D × wb_high + wb_offset) described by that
    module. No source code from darktable has been copied or incorporated.

  rawspeed camera colour matrices — rawspeed contributors (LGPL-2.1)
    https://github.com/darktable-org/rawspeed
    src/OpenRevelare.Core/CameraMatrixFallback.cs carries the per-camera
    ColorMatrix values from rawspeed's cameras.xml, used when the bundled
    LibRaw has no colorimetry for a body. These are the camera manufacturers'
    published DNG ColorMatrix figures — the same data Adobe ships in DNG
    Converter and LibRaw stores as cam_xyz — not rawspeed's own creative work,
    and no rawspeed source code is incorporated. Regenerate with
    docs/calibration/gen_fallback_table.py.
