## 准备工作

**翻拍设置（相机 RAW）**

- 相机设置为 **UniWB**（即手动白平衡，所有通道增益相等）。软件解码时会关闭相机白平衡，但相机本身的预览图若偏色属正常现象，不影响处理结果。
- 灯箱或光源均匀照亮整个负片，确保片基区域（齿孔、边缘空白）曝光充足，用于后续 T_base 采样。

**强烈建议：拍摄含片头的帧**

每卷胶片的起始位置都有一段「片头」——完全曝光区（正片上应为纯黑）与未曝光片基区（橙色底版）在同一画面内并排出现，中间有清晰的分界线。一帧片头就集齐了整套标定需要的参考区域：

- **T_base 采样**：框选橙色片基区（未曝光部分）
- **D_max 采样**：框选完全曝光的纯黑区
- **wb_offset 采样**（阴影端白平衡）：纯黑区也适合做阴影白平衡参考——未曝光区三通道理论上应等 D_min，是天然的阴影端参考
- **wb_high 采样**（高光端白平衡）：完全曝光区三通道均为 D_max，是天然的高光参考

理想情况下，T_base 与 wb_high 可用同一片基选区，D_max 与 wb_offset 可用同一纯黑选区——一帧片头就能完成全部四个参数的标定，无需在多帧之间切换。其余内容帧保留足够宽的齿孔/边缘空白供 T_base 采样即可。

**扫描仪 TIFF**

导入 TIFF 时，软件会**自动探测**首张文件的元数据并显示在导入对话框的「扫描仪输出编码」框上方，供确认：尺寸、位深、是否嵌有 ICC Profile（及其名称、是否含设备原色矩阵「+矩阵」）、推断的 gamma 类型与拟合数值（如 `γ≈1.56`）。同时根据探测结果**自动预选**编码选项，通常无需手动判断：

- **线性**：扫描仪已输出线性光，不做 gamma 转换。
- **sRGB gamma**：标准 sRGB 编码，自动套用逆 sRGB 曲线还原线性。
- **自动检测**：当文件带有非标准设备 gamma 的 ICC（如 Flextight、Noritsu 等专业扫描仪的设备 Profile）时自动选中——软件用文件**自带的 TRC 曲线**逐通道精确逆 gamma，并进一步应用 ICC 设备原色矩阵（rXYZ/gXYZ/bXYZ），将扫描仪设备 RGB 转换为标准 sRGB 线性。这两步合并解决了扫描仪三通道 gamma 不一致导致的"亮度相关色偏"问题。无 ICC 或缺矩阵标签时各步骤单独回退。

探测结果只是预选，可手动覆盖。整卷模式下按首张文件探测并应用于全卷（同一扫描仪同一设定，参数一致）。

**TIFF 路径的 chroma_grade**

载入扫描件时会读取其嵌入的 ICC Profile：先用 Profile 自带的三条 TRC 曲线逐通道线性化，再用 rXYZ/gXYZ/bXYZ 矩阵把设备 RGB 映到 sRGB 线性光。

TIFF 导入时 `chroma_grade` 默认为 **1.0**（不额外放大色度），RAW 导入默认为 3.05。这个分野目前没有站得住的依据——它原本的理由（3.05 补偿相机 sensor 串扰）经追溯不成立，详见 [CALIBRATION.md](../../../../docs/CALIBRATION.md)。保留现状是为了不改变既有工程的输出。

文件没有 ICC、或 Profile 只有 LUT 没有矩阵标签时，相应步骤跳过，扫描仪的通道差异不被校正；此时若有色偏，用 SceneBase 的饱和度与白平衡回收。需要直接改这个系数，走工程文件的 `chroma_grade` 字段或 CLI 的 `--chroma-grade`。

> 提示：若导入的是 8-bit TIFF，反转的对数密度运算在暗部只有有限的级数，可能出现轻微色带。条件允许时建议从原始扫描导出 16-bit。

## 导入文件

点击工具栏「新建项目」或菜单「文件 → 新建」，弹出导入对话框。

**文件选择**

拖拽文件或点击「添加文件…」。支持格式：
- RAW：ARW、NEF、CR2/CR3、DNG、RAF、RW2、ORF、PEF 等主流格式
- TIFF：来自扫描仪的 .tif / .tiff

同一项目只能混用同类文件（不可 RAW 与 TIFF 混合）。导入多个文件时自动进入**整卷模式**，共享 FilmBase 参数。

**光源选择（仅 RAW）**

- **宽谱光源（白光）**：使用钨丝灯箱或日光灯箱翻拍时选此项，直接进入密度处理，无需校正图。推荐大多数用户使用。
- **窄谱光源（RGB 合成）**：使用 RGB 单色 LED 灯箱时选此项，需要同时提供三张校正图的目录。详见「[Path A 窄谱光源工作流](#path-a-窄谱光源工作流)」。

**导入后：齿孔遮罩确认窗口**

RAW 卷导入完成后，软件会自动弹出**齿孔遮罩确认**窗口。软件从全卷中找出片基最亮的那一帧（最坏情况帧）作为预览，在窗口中显示。

**目标**：用绿色叠加层标记出**齿孔和翻拍光源**（最透光区域），避免污染后续的片基标定并去除齿孔。

**操作**：拖动阈值滑块调整分界线，窗口会实时刷新绿色区域：
- **绿色应覆盖**：齿孔孔洞、灯板透光区（过曝区域）
- **绿色不应覆盖**：负片橙色片基、任何有画面内容的区域

**阈值如何确定**：软件使用**亮端断层谷检测算法**自动计算初始阈值——在灯板峰（最亮区域）与片基峰（次亮区域）之间找到最深的谷值作为分界线，从亮端扫描避开暗端纯黑区域造成的次级波谷。这个自动检测值通常已经够准，可再按实际画面微调。

**特殊情况**：
- 如果灯板与片基亮端间隙较窄（< 0.08），需要仔细微调阈值。窗口下方会显示参考数值（灯板亮度、片基亮端、间隙）。
- 如果这卷**无齿孔且无光源露出**（如 120 中幅，画面完全覆盖胶片），点「**这卷无齿孔(跳过)**」。
- 关闭窗口或按 Esc 等同于跳过，齿孔遮罩保持关闭。

调整满意后点「**确认并继续**」，此阈值整卷统一应用。

**自动片基检测**：确认齿孔遮罩后，软件会自动对整卷进行片基检测（使用齿孔阈值排除灯板像素），将结果写入所有帧的 T_base 初始值。检测结果显示在状态栏，**仅供参考，建议手动框选片基区域重新标定**以获得更准确的结果。可在「设置 → 偏好设置」中关闭自动检测。

## FilmBase 标定

FilmBase 面板包含所有物理还原参数的标定操作，对应处理管线的第一阶段。每个参数都有对应的「采样」按钮——点击按钮后，在预览图上框选一个矩形区域，软件自动从该区域计算对应参数值。

> 标定顺序很重要，请按以下顺序操作。

### 1. 采样片基（T_base）

在预览图上框选**未曝光的片基区域**——通常是齿孔之间的空白部分，或画面边缘的橙色底版区域。选区不能包含任何曝光画面内容。

片基采样是最重要的一步。它同时消除橙色底版和 D_min 偏移，是后续所有密度计算的物理基准。

### 2. 采样阴影白平衡（wb_offset，可选）

框选画面中应该呈中性灰/黑的深色区域（如完全曝光的纯黑区、黑色织物、暗部阴影），令三通道密度对齐，消除阴影端色偏。**若已按片头方式标定，完全曝光区（纯黑区）就是理想选区。**

**建议顺序：先采样暗部 WB，再采样亮部 WB**，避免两端标定相互干扰。

### 3. 采样高光白平衡（wb_high，可选）

框选画面中应该呈中性白的高光区域（如白纸、白墙、灰卡）。软件自动将三通道密度对齐，消除高光端色偏。**若已按片头方式标定，完全曝光区就是理想选区——该区域三通道均为 D_max，是天然的高光参考。**

### 4. 采样 D_max

框选画面中**最暗的区域**——通常是曝光过度的遮光区、齿孔外侧，或画面中最深的阴影。D_max 决定反转后的白场位置。

整卷模式下，软件会在全卷所有帧中取最大值，保证整卷白场一致。

### 5. 采样曝光偏移（scan_exposure_ev，可选）

**用途**：将片基精确压到密度 = 0，使正片中的片基区域呈现纯黑。

T_base 采样消除的是片基的颜色（橙色偏移），但不保证片基的绝对亮度恰好落在密度零点。如果翻拍时灯箱亮度有波动，或镜头焦面边缘有轻微衰减，片基区域的实际密度可能有残留偏差，导致正片中片基发灰而非纯黑。

操作：框选与 T_base **相同的片基区域**，软件测量其相对当前 T_base 的残留密度，算出整体补偿的 EV 值并写入。正值提高整体密度（把偏亮的片基压暗），负值降低。多数情况下此值接近 0；若正片片基区域仍发灰，再用此步微调。

### 6. 调整 grade（可选）

- **grade**：控制正片对比度，相当于传统暗房的相纸号数。默认 1.65 适合标准 C-41 消费彩负；ECN-2 电影负片可能需要降低到 1.4–1.6。
- **chroma_grade**：在密度域整体缩放色度，GUI 中不开放调整，由输入类型决定——RAW 导入用 3.05，扫描件导入用 1.0（见上文「TIFF 路径的 chroma_grade」）。

  这个参数的依据薄弱，正在被真正的色彩空间渲染取代，详见 [CALIBRATION.md](../../../../docs/CALIBRATION.md)。日常想让画面更浓或更淡，请用 SceneBase 的**饱和度**滑块。确实需要改这个系数时，两条路径可用：工程文件里的 `chroma_grade` 字段，或 CLI 的 `--chroma-grade`。

## 预览与裁切

FilmBase 标定完成后，预览图自动更新为正片效果。

**缩放与平移**：鼠标滚轮缩放，拖拽平移。

**裁切**：在裁切面板选择格式预设（135 全幅、半格、XPan、120 645/6×6 等），或手动拖拽裁切框。裁切是无损操作，随时可以重置。

**旋转与翻转**：在几何面板调整水平/垂直翻转和任意角度旋转（用于校正翻拍时的轻微倾斜）。

**齿孔遮罩**：启用后，软件自动检测并遮盖齿孔区域，将其涂为白色，避免齿孔出现在导出文件中。阈值参数控制检测灵敏度，适合损坏或不规则齿孔。

## SceneBase 调整

SceneBase 面板包含审美调整参数，所有操作均实时预览，对 FilmBase 的物理还原层无影响。

| 参数 | 说明 |
|------|------|
| 白平衡（色温/色调） | 正片域白平衡，用于细微色温微调 |
| 曝光 EV | 线性亮度缩放，调整整体曝光 |
| 黑场 / 白场 | 色阶拉伸，线性映射 |
| 对比度 | S 形曲线，不引入色相偏移 |
| 饱和度 | 线性域色度缩放，非色相轮旋转 |

**输出意图**（影响导出内容）：
- **NONE（线性）**：跳过 Stage 2，输出 FilmBase 的线性正片。适合交给 DaVinci Resolve、Nuke 等专业调色工具继续处理。
- **BASIC（sRGB gamma）**：执行完整 Stage 2 后处理，输出带 gamma 编码的标准图像，可直接用于分享或打印。

## 整卷操作

导入多个文件时，软件进入整卷模式。胶片条显示在界面左侧，点击缩略图切换到对应帧。

**将参数应用到全卷**：在 FilmBase 或 SceneBase 面板，任意参数旁边有「应用到全卷」按钮。点击后，当前帧的该参数值复制到整卷所有帧。

**查看全卷（Contactsheet 模式）**：点击胶片条顶部的「查看全卷」按钮，主预览区切换为整卷缩略网格（Contactsheet）。在此模式下：

- **整卷范围内采样**：可以在 Contactsheet 上直接框选 T_base、D_max、wb 等参数——框选结果自动广播到整卷所有帧，是整卷统一标定的最快路径。
- **整体预览色调**：所有帧以当前参数实时渲染，可直观判断整卷色调一致性。
- 点击任意缩略图，自动退出 Contactsheet 模式并跳转到对应单帧。

整卷标定建议流程：
1. 进入 Contactsheet 模式，在全卷网格上框选片基区域完成 T_base 采样（自动广播到整卷）。
2. 同样在全卷网格上框选最暗区域完成 D_max 采样。
3. 退出 Contactsheet 模式，对需要单独调整的帧（过曝、偏色严重）单独微调。
4. 在 SceneBase 完成审美调整后，选择是否应用到全卷（通常每帧独立）。

**虚拟副本**：对同一帧想保存多种 SceneBase 设定时，右键缩略图创建虚拟副本。虚拟副本与原帧共享 FilmBase 参数，SceneBase 参数各自独立。

## 导出

点击「导出」按钮（或菜单「文件 → 导出」）。

**格式选择**：
- **TIFF（16-bit，AdobeRGB）**：最高质量，适合后续调色或存档。
- **JPEG（sRGB）**：直接可用，文件更小，适合分享和网络发布。

**分辨率**：无限制。

**输出目录**：可在导入时指定，也可导出时临时选择。整卷导出时所有帧输出到同一目录，文件名自动以原文件名命名。

## Path A 窄谱光源工作流

Path A 适用于使用 RGB 单色 LED 灯箱（R/G/B 三色分别控制）翻拍负片的用户。

**拍摄校正图**

在不放胶片的情况下，分别用 R 灯、G 灯、B 灯照亮空白灯箱并拍摄，得到三张校正图。**无需特定命名**，只需放置在同一目录中，软件会通过内容分析（argmax）自动识别哪张是 R/G/B。

**调光模式（两种均可）**：
- **白光模式**：调整 R/G/B 强度使混合光为纯白
- **片基中性模式**：调整 R/G/B 强度使片基透光为中性，物理抵消色罩

**导入时选择 Path A**

在导入对话框的光源选项中选「窄谱光源（RGB 合成）」，然后选择校正图所在目录。软件会自动识别 R/G/B 三张校正图并弹出确认对话框，显示识别结果和每张图的 ROI 均值。如果识别有误，可通过下拉菜单逐通道纠正后再确认。

**标定流程与白光相同**

导入完成后，FilmBase 标定流程与 Path B 完全相同：依次采样片基、白平衡、D_max。解耦矩阵在导入时已自动计算，α 参数（解耦强度）由软件从全卷样本自适应确定，无需手动干预。

## 常见问题

**正片偏色/偏绿**

最常见原因是 T_base 采样区域包含了曝光内容，或采样区域不够均匀（如片基边缘有轻微曝光）。重新采样片基，确保选区落在完全未曝光的橙色底版区域。

**高光发灰，没有纯白**

D_max 采样区域不够暗，导致白场设置偏低。重新选择画面中最暗的区域采样，或适当降低 D_max 数值。

**颜色还原偏淡（ECN-2 电影胶片）**

ECN-2 的色度特性与 C-41 不同，默认 chroma_grade = 3.05 可能不足。在 SceneBase 的饱和度滑块向右微调即可；要直接改系数，走工程文件的 `chroma_grade` 字段或 CLI 的 `--chroma-grade`。

**导出后颜色比预览偏淡**

预览使用近似的快速路径，导出使用高精度浮点运算，两者之间存在微小差异属正常。如果差异明显，检查输出意图是否设置正确（BASIC / NONE）。

**Lensfun 无法识别镜头**

EXIF 中的镜头型号格式在不同相机厂商间存在差异。可在设置中手动指定相机型号和镜头型号，覆盖自动检测结果。如果镜头不在 Lensfun 数据库中，跳过此步不影响核心反转效果。
