# 第一卷：从导入到重新打开

目标是先得到一卷可继续编辑、可以重新计算的正片。源文件保持不变，修改保存在 `.ncproj` 工程中。详细参数见「操作指南」，公式见「技术原理」。

## 1. 导入同一卷的原片

添加同一卷的 RAW 或 TIFF 文件。相机白光翻拍使用默认的 Path B；只有使用 RGB 窄谱光源并准备了对应的三张参考图时才选择 Path A。同一卷使用同一种输入族；RAW 平场配 RAW，TIFF 平场配 TIFF。

通常只需添加原片并导入；扫描分割、光源与平场选项集中在“高级导入设置”中。选用 Path A 或 LCC 时，界面会提示所需参考并在准备好前阻止导入。

默认保留自动整卷分析。有效的 TIFF ICC 会优先使用；只有文件缺少可信声明时才出现输入解释提示，请根据扫描软件实际输出确认“sRGB”或“线性”。不要用调色去掩盖错误的输入解释。

**完成标志：**胶片条出现这一卷的帧，当前画面可查看，后台分析有进度。**失败恢复：**看状态栏里的文件名和原因；先用一张原片确认格式可读，再重新导入。不要把导出的 JPEG 当作负片原始输入。

## 2. 等整卷分析结束，再检查标定

导入会先显示当前帧的临时反转结果，随后汇总整卷。等待“整卷分析”结束，再检查 Cineon 页面里的片基与高光端点证据。

片基是干净、未曝光的透明底版；高光端点来自场景代理，不能当作实测的胶片最大密度。整卷都没有可靠裸片基时，自动结果可能只是内容推断。

需要手动片基取样时，在负片边缘框选均匀、未曝光的底版，避开文字、灰尘、齿孔和灯板。换了光源、设备校正或平场之后，重新分析，再检查端点。

**完成标志：**分析提示消失，片基来源与置信度能够解释当前结果，代表帧没有明显整体色偏。**失败恢复：**检查输入解释、原片边缘与参考文件；修正后重新运行“自动（整卷）”。它会重设标定端点及黑白场偏移，因此已精调的卷应先保存工程副本。

## 3. 复用标定，再逐帧调整

在代表帧确认标定后，按需把标定应用到整卷；如果导入的整卷分析已经统一标定，就无需重复同步。Display 页面用于逐帧的色温、色调、曝光、反差、饱和度与曲线。

需要复制场景调整时，先复制 Display 参数，再在胶片条勾选目标帧并粘贴；先检查“同步项”中启用的分组。面板调参作用于当前帧，勾选集合用于明确的批量命令。

方向、裁切与齿孔有各自的应用操作。画面构图不同的照片不要直接同步裁切。批量操作成功后可以一次撤销；任一目标原片不可用时整组不应用，选择保留，修复文件位置后重试。

**完成标志：**前后切换几张代表帧，整卷颜色一致，逐帧曝光保留场景差异。**失败恢复：**立即撤销这次同步，检查来源帧、目标勾选与同步分组；不要继续改动来抵消误同步。

## 4. 先导出一张，再导出整卷

选择一个输出目录，避免覆盖原片。分享用途通常选择 sRGB JPEG；需要继续后期时可选择 16-bit TIFF。HDR、线性 DNG 和 ACEScg 主文件有各自的输出约定，应在明确下游软件支持后使用。

先导出一张包含暗部、高光和中性色的代表帧，在有色彩管理的查看器中检查。确认格式、色彩空间、尺寸与命名，再执行整卷导出。留意勾选目标及冲突处理选项。

导出时直接选择格式与尺寸：JPEG 适合分享，TIFF 适合继续修图；也可选择 HEIC、线性 DNG，或在 TIFF 中启用场景线性 ACEScg。文件沿用本卷的 SDR/HDR 与渲染空间，不会自动把 P3 或 Adobe RGB 改为 sRGB。需要填写胶片拍摄信息时，打开右侧信息栏。场景线性 TIFF 不包含成片调整，也不能代替原片、工程及参考的完整归档。

需要普通 SDR 查看器兼容时，HDR JPEG 提供 SDR 基图与增益图；基图使用最终 HDR 主图的色彩。HDR HEIC 默认是 BT.2020/PQ，也可选择带 SDR 主图的 Adaptive HDR 标准增益图；浮点 HDR TIFF 是线性主文件，两者仍需要正确解释其色彩标记的查看器。

**完成标志：**状态栏显示导出完成，输出文件能打开，尺寸和颜色符合预期。**失败恢复：**确认目录可写、磁盘空间足够、原片仍可读取；保留原片与工程，修复问题后重试。

整卷导出结束会显示逐帧结果。关闭应用后，重新打开同一工程，从“文件 → 查看上次批量导出结果”即可查看并一键重试失败或未执行项；已成功的文件不会再次导出。重试沿用任务开始时的参数与目标路径，并重新读取当前原片。

结果入口不依赖当前帧能否显示，结果会标明原任务的卷名、时间与格式。若工程、LUT、校正参考或已完成的输出文件在任务开始后改变，旧任务会保留结果供查看，但需创建新的整卷导出任务，避免混用不同的色彩依据或覆盖已改变的文件。

## 5. 重新打开，确认工程可恢复

等自动保存完成，再返回图库或关闭。下次从图库打开同一卷，检查一帧的曝光与裁切是否恢复。源目录可写时，工程在原片旁；不可写时使用用户配置目录下的 `rolls` 回退位置。

状态栏独立显示“待保存 / 保存中 / 已保存 / 保存失败”，悬停可查看工程路径与最后保存时间。保存失败可点击重试；关闭时失败会保留窗口，允许重试、另存恢复副本或明确放弃修改。

移动归档时同时保留原片、`.ncproj`，以及所用的平场、Path A 参考图和自定义 LUT。工程不包含原始照片，也不把所有外部参考资产打包进去。

从“文件 → 查看工程依赖”检查外部资源的路径、使用帧和缺失状态，并可导出 JSON 清单。同一文件只列一次，虚拟副本也会计入；已关闭但仍声明的参考保留在清单中。文件存在不代表内容或校正版本有效，仍需处理界面的参考警告。清单包含完整本机路径，分享前请检查；导出清单不会复制照片或参考。

工程文件中已有的相对路径会按 `.ncproj` 所在目录解析，而非应用启动目录。保持目录布局一起移动即可继续解析；重开后的自动保存也会保留相对路径。

选择“文件 → 归档工程与原片”，再选择存放位置，应用会新建目录并复制原片、已声明的校正文件和自定义 LUT；完成后生成 `project.ncproj` 和 `checksums.json`。保留整个目录即可移动或备份。归档使用操作开始时的调整快照，原工程仍照常保存。资源缺失、拷贝中发生变化、取消或写入失败时不会发布半成品目录；校验清单中的 SHA-256 可用于日后核对文件。

校正参考缺失时，工程保留原来的 Path A/B 与 LCC 启用选择，并持续提示；恢复参考前不能导出降级结果。点击“恢复工程参考”选择新目录；不同目录中的参考可分别恢复。新保存的工程用文件长度和首尾采样指纹检查重定位，不是完整文件校验和；旧工程没有指纹时，会额外要求确认同名原片。

恢复操作只替换不可用的参考，先校验找到的平场和 LUT，再写入工程；无效候选不会覆盖原声明。编辑期间参考被修改时，需要明确恢复／重新载入或重新打开工程；失败或取消的校验不会偷偷替换活动 LUT。正常替换原片并保存后，重定位指纹会随新原片更新。

移除帧及其副本、创建副本、添加与排序都可以撤销；移除只影响工程，不删除原片。LCC 启用选择按整卷保存；旧工程没有卷级字段时使用第一帧的声明，完全没有声明才沿用参考存在时启用的兼容行为。

**完成标志：**重新打开后帧列表、标定、逐帧调整和构图与关闭前一致。**失败恢复：**先核对打开的是同一个工程，检查原片和参考路径；遇到保存失败时不要继续切卷，先解决目录权限或磁盘问题并重试保存。

## 工作过程中替换了文件

应用会在读取缓存及提交后台结果时检查文件版本。同一路径的原片改变后，下一次读取会重新解码；处理途中改变的结果会被拒绝。平场或校正参考图改变时，请显式重新载入参考并重新标定，或重新打开工程；应用不会静默替换颜色依据。

仍在屏幕上的图像可能是上一次有效预览。收到文件变化或读取失败提示后，先恢复／重新载入文件，再继续采样或导出。
