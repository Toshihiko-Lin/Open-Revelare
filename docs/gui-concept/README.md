# OpenRevelare：按工作流程重新设计 GUI

概念版本：2026-11-01。状态：保留为产品与交互探索；生产实现已开始，见 [审计实施进展](../gui-audit/05-polish-progress.md) 与 [实际界面渲染](../gui-audit/ui-review.html)。

根据用户后续澄清，保留现有 GUI 的基本架构：图库／修片、胶片栏、主预览、底片校准／成片调整。目标是更清晰、顺手、自然，减少刻板步骤和额外规划。

## 当前视觉稿

此前的生图 `gui-visual-reference.png` 已被用户否定，不再作为实现参考。新版用 **StageShow + Interface Design + Impeccable** 实际编写，见[可操作工作台](workbench-preview.html)、[浅色截图](workbench-light.png)、[深色截图](workbench-dark.png)与[源码和验证记录](stageshow/README.md)。新版保留三栏，收敛参数容器、强调色与说明，让影像占主导。此设计稿尚未替换桌面程序的视觉层。

推荐概念：**熟悉的修片工作台，更顺手的交互**。

流程用于决定控件的位置、默认展开项、提示时机和操作反馈，不增加四阶段导航、基准草稿或任务完成度系统。

- [完整 GUI 概念](workflow-concept.md)：任务、屏幕、按钮、作用范围、状态、异常、键盘、窄屏和能力归宿。
- [GitHub skill 筛选](skill-research.md)：实际读取的原始文件、适配判断、版本约束和使用边界。
- [交互与实施契约](interaction-contract.md)：新概念与现有行为的差异、数据依赖及原型验收。
- [体验假设](experience-hypotheses.md)：拖放、上下文键位、缩放锁定、就地撤销、参考帧等值得试的方向及副作用。

聊天中的界面概念沿用现有三栏，可以切换底片校准／成片调整、切帧、勾选批量目标、调参数和打开导出摘要。重点展示控件关系、实际作用范围和及时反馈。

先前提出的四任务视图和新增基准版本模型已撤回，不属于本轮建议。概念演示只模拟交互，不处理 RAW、写工程或导出文件；图像是仓库示例。

本轮概念验证：切帧参数隔离、批量粘贴目标与清除选择、上下文键位、对话框初始焦点／Esc、拖放与重复文件名预检、导出格式摘要通过浏览器检查；图库／修片在 1024、850、736、360、320px 检查了控件边界，并查看浅深主题截图。窄于桌面工作尺寸的堆叠仅为聊天概念可读性，不是生产桌面布局结论。未执行 Avalonia 运行测试。
