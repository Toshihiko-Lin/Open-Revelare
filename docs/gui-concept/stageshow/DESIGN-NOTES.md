# 摄影工作台 · 视觉与交互研究

本轮采用 StageShow 的真实 React kit，Interface Design 的层级与领域探索，以及 Impeccable 的 Operate、Quieter、Craft floor。不是生产引擎或功能验收。

使用者刚完成底片翻拍，要从一卷中选一张判断片基，再得到整卷一致、可继续修片的正像。感受应接近精密但安静的摄影工作台。

领域：接触印样、灯箱、片基、密度端点、灰卡、整卷一致性。色彩世界：灯箱白、相纸灰、底片边框黑、金属中灰、密度仪墨色；负片橙和照片色只存在于影像内容。签名是保留底片边缘的正像、纵向接触印样和与片基框选相连的端点读数。

避开的默认套路：卡片套卡片改为连续的参数栏；大块彩色按钮改为有限的操作强调；反复的阶段编号与解释改为共享对齐线、组间距、工具出现后的局部提示。

## 组件约束（写代码前）

- Intent：以照片判断为主，控制区可快速精确操作。
- Hierarchy：中央照片是唯一主角，右栏约 292px，左栏 112px。顶栏只是导航，底栏承接输出。
- Palette：无色相的中性围场，去饱和蓝灰只表达操作和选择。日间浅色 / 夜间深色同时保留。
- Depth：主要靠表面亮度区分，栏间仅一条轻线；不叠加卡片阴影。
- Surfaces：影像围场与控制面板区分；输入值比面板稍暗，强调可编辑。
- Typography：沿用项目 Segoe UI / 中文系统字体；12–14px 紧凑工作密度，字重和颜色承担层级。测量值使用等宽数字。
- Spacing：4px 基准；栏内 16px，相关操作 8px，组间 24px。控件 30px 高；不为装饰撑高行。

## 演示计划

从 StageShow `hero-demo` 复制 Stage + Act 的测量目标与框选结构，保留其光标因果和停止在结果的 poster，重新构造产品布局。先检视静态，再演示：片基采样激活 → 在胶片边缘框选 → 黑端示例读数更新 → 比较结果 → 停留。只演示一个因果，不播放装饰开场。宽屏完整三栏；窄屏是对这一操作的局部特写，不冒充软件已有手机版。

所有读数为明确的演示数据，不代表对项目 JPEG 素材做了真实密度分析。StageShow 光标不驱动 Avalonia。生产实现继续使用原有控件和渲染链路。
