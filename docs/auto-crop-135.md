# 135 自动裁切

裁切面板以通用手动裁切为主，下方的「135 辅助识别」默认折叠，点击标题展开。手动比例预设不控制自动识别。

手动裁切为主，排在上方，适用于全部片幅：比例、拖框/清除、拉直、参考线和同步裁切。135 专用辅助位于下方的一个折叠区内，明确标注适用范围；不增加确认、锁定或审批操作。失败时只显示当前帧的一行说明，仍可直接用上方手动工具调整；撤销和已有的恢复入口保留。用户主动重新识别可更新目标帧已有裁切。

在「135 辅助识别」选择「仅画面 3:2」或「含齿孔 35:37」，再点击「识别本帧」或批量按钮。有勾选时只处理勾选帧，没有勾选时处理整卷。横幅输出分别为 3:2、37:35，竖幅分别为 2:3、35:37。

操作结束只显示“已裁切 N 帧，保留原框 N 帧”，读取失败时附带数量。保留原有勾选范围，便于再次操作。

## 定位与居中

翻拍不要求画面位于原始照片中心。检测器在每帧实际位置寻找画面，裁切后才使画面居中。

含齿孔模式沿胶片方向以检测到的画面左右边界中点定位，等量保留两侧余量。边界处同分的搜索窗口不能作为实际边界：通过亮度过渡的加权中心精修边线，避免两条边一起偏向一侧。跨胶片方向先由两排齿孔估计片宽和中心；齿孔外侧的上下片边都可见且间距一致时，用实际片边约束中心和最大宽度。片边无法分辨时保留齿孔标尺估计，结果仍需检查。

识别从未裁切、未反相的线性预览开始，先应用与显示和导出相同的镜头几何校正、旋转和翻转。齿孔的周期性提供独立物理标尺：孔距 4.75 mm、排距 28.17 mm。检测器比较画面与片基肩部的 log-RGB 差异，检查全幅片门尺寸、边界、片基稳定性和齿孔可见性。可靠的小倾角可以自动拉直，修正后的坐标用于裁切。

上下边缘截断了部分齿孔时，只要仍有两排可匹配的周期孔列，就保留标尺证据。孔列的内侧边缘用于测量角度，避免可见孔洞的重心因截断而偏移；拉直后如果填充角造成标尺测量矛盾，使用原标尺变换到校正坐标。片门边缘紧靠照片左右边缘时，允许从画格内侧验证附近齿孔；片基采样也随可观测的上下片门边界调整，避免把略宽片门内部当作片基。

## 批量互校

批量操作先逐帧检测，再尝试校正缺边或尺寸异常的帧，无需新增开关。

- 至少三张齿孔检测结果在源尺寸、横竖方向、极性、片宽、片门长度和总拉直角度上相符，且一致组占至少三分之二，才形成几何参考。角度比较计入原有手动拉直；以中位数及离散程度判断哪些测量需要复核。
- 参考不包含位置；每帧仍需自己的齿孔标尺及曝光边线。因此翻拍位置变化不会被拉回参考帧或原图中心。
- 少一条边时，使用本帧可见边线定位，结合已验证的片门长度推算另一条边。边界模糊形成的异常片门长度也可以再次校验。
- 画格外侧的齿孔被片夹遮挡或没有落入当前可见区域时，整卷尺寸可以支持验证内侧孔列，但必须检查边界两侧的片基连续性，防止把片夹的黑边当作曝光边线。若片基边缘有杂色或污迹，再用四条实际边线、孔列标尺和参考尺寸共同确认，优先采用实测边界。
- 整卷倾角是复核先验，不强制每帧相同。已有完整边界和孔列支持的帧不会仅因倾角不同被丢弃；弱帧倾角超出统计范围时，须在至少两种亮度分割阈值下重新得到一致孔列、位置、尺度和角度，才继续恢复裁切。
- 空白帧、缺少齿孔、尺寸变化、极性不明确、明显内部框线、双半格、片基变化或多个同样合理的位置不会强行应用互校结果。
- 互校来源随工程保存，不增加确认流程。没有足够参考或本帧证据时，保留原裁切和拉直。整卷处理逐帧读取弱帧，不保留整卷浮点预览。

整卷参考和应用范围相互独立。本帧或少量勾选帧可以复用同卷其它帧的有效测量，参考帧不会因此应用裁切。没有现成参考且目标帧证据不足时，最多读取六张其它原片寻找至少三张一致锚点；虚拟副本不重复计作独立锚点。参考仍不足则保留原框。缓存中的不同倍率不强行约束本帧可靠孔列，输出规划也排除不相容倍率的上下文。

检测缓存最多保留 256 项紧凑独立测量，不保存图像；源文件版本、方向、拉直、实际镜头几何和输入解码方式决定有效性。曝光、白平衡、暗角和输出模式不改变测量，自动拉直后可以复用已校正坐标。互校推断不会被缓存为独立锚点，避免自我验证。齿孔多阈值搜索共用一次亮度及分位数计算。

未检测到齿孔而退回内容搜索的结果，也必须接受整卷几何检查，不能以错误的竖框或局部小框绕过参考。可靠孔列本身支持的横竖组分别统计，不依据画面人物或建筑的朝向自动旋转照片。

同组裁切使用共享尺寸及 3×2 / 37×35 的整数像素倍数，并按像素边界放置。内容模式内缩以避免露出片基；含齿孔模式受片宽约束。目标范围超出输入时跳过，不平移补救、不生成缺失片边。

## 稳定性与回退

这是辅助检测。低对比、夜景、漏光、片头、片夹遮挡及画面内部强边线均可能导致失败或误判；内部检测得分不是正确率。批量互校增加几何约束，不能恢复不存在的图像信息，也不能保证单边线属于真实片门。

GUI 不应用不确定推测框。失败保留原裁切，成功结果也需检查；可直接手动拖框调整、撤销或「恢复识别前」。手动裁切适用于全部片幅，参考框同步适合位置和倍率稳定的翻拍。自动识别仅适用于每张翻拍包含一个完整 135 全幅画格，不适用于半格、XPan 或已拆分的长条扫描。

所有结果检查后一次性写入，批量可一次撤销。取消、换卷、切帧、改动参数或源文件变化会阻止过期结果写入。恢复备份及检查提示保存到工程；恢复只改变裁切、方向和拉直，不改变镜头或成片设置。
