# 相机翻拍与扫描仪的校准参考材料

核查日期：2026-11-18。本文规定参考采集与获取路线，不宣称当前应用已实现拟合或校正。普通导入无需这些材料。

## 相机翻拍：先校正采集，再讨论颜色

第一层目标是同一设备、镜头、光源和几何下的采集响应。记录相机型号／序列号、镜头、光圈、ISO、快门、倍率、焦点、灯板工作模式、解码版本与所有已有处理。厂商矩阵、光谱和响应资料可登记，但必须说明来源和测量条件；仅有色温不足以确定灯板 SPD，直接拍纸质色卡形成的 DCP 也不能直接证明负片染料透射测量正确。

建议第一轮固定采集条件：

1. 固定片架、灯板、镜头和相机，让光源状态稳定。以无片图检查各通道，选择参考与内容均不截断的固定设置；不预设所有相机使用同一数值阈值。
2. 遮光采集同设置暗场；保留原 RAW，不由外部修图软件自动扣黑或调色。
3. 在胶片位置移除负片，保留光路和片架，采集无片场。它记录灯板／光路在设备通道中的响应，不是在镜头前随便放张白纸。
4. 每种参考重复采集，以便后续估计稳定性。无片场若已承担空间归一化，不能再重复应用消除同一响应的 LCC。
5. 独立验证使用另一组参考和同片重复采集；若增加不同曝光实验，明确曝光比例，不能未经验证直接混用不同曝光的 dark/open。

暗场／亮场是标准采集校正思路，参考 [Basler 的说明](https://docs.baslerweb.com/flat-field-correction-%28pylon-viewer%29)。该资料针对工业相机，具体采集次数、阈值和设备内校正不能原样作为所有消费相机的规范。

计划公式为 CFA 域 `(sample-dark)/(open-dark)`，前提是读取同一尺度且未重复扣黑的采样。当前 LibRaw RGB 已执行扣黑和缩放，不能将原始暗场计数直接再从该 RGB 减去。第一版校正计算应先实现独立 CFA 契约，并明确 white／black levels、相位、active area、坏点及参考适用条件。

第二层才是颜色表征：可拍摄具有参考值的透射色靶来建立受限的输入 ICC／色度配置；若目标是标准密度，则需要明确测量域的密度或光谱参考；若目标是原场景颜色，则需要拍到胶片上的参考以及胶片＋实际冲洗的联合模型。反转片 IT8 表征不能直接当作彩色负片通用反演。

## 扫描仪：型号决定工作方式，色靶编号决定参考数据

所需材料不是“一份对应型号的校准文件”，而是以下组合：用户这台扫描仪、可放入的实体色靶、该色靶对应的批次／单件测量文件、固定设置下的本机扫描。参考数据不按扫描仪型号匹配。[VueScan 官方流程](https://www.hamrick.com/vuescan/html/vuesc17.htm)明确使用色靶扫描及对应数据生成 scanner ICC。

- 胶片透射模式：选择能放入片架的 IT8.7/1 透射靶，例如适用片架的 35mm 或大幅面靶。
- 纸稿反射模式：使用 IT8.7/2 反射靶。反射配置与透射配置分开保存。
- 厂商硬件白校准／焦点靶：按具体型号说明书取得和执行，不能与色彩 IT8 混为一谈。例如 [Hasselblad X1/X5 官方手册](https://cdn.hasselblad.com/a99c4b40-9059-4122-afd2-04e004395e55_x1-x5-scanner-manual-v1.5_eng.pdf)区分焦点及反射白校准；OpenRevelare 不冒充驱动的硬件维护功能。

实际获取渠道（价格、库存、运输需用户向供应方确认）：

1. **随扫描仪附带的色靶。** 先检查靶本体／保护套上的供应商、型号、批次或条码。寻找相同编号的参考文件；扫描仪型号相同并不保证靶编号相同。
2. **LaserSoft Imaging / SilverFast。** [官方参考数据页](https://www.silverfast.com/it8calibration/en.html)提供其色靶数据；[官方使用说明](https://www.silverfast.com/information-on-the-use-of-it8-targets-and-resolution-targets/)说明批次与单件测量、条码和参考对应。需要先取得实体靶，下载文本或打印靶图片不能代替透射靶。
3. **Wolf Faust / ColorReference。** [官方色靶及参考页](https://www.colorreference.de/targets/index.html)列出反射、35mm 和大幅面透射靶及参考下载。选物理尺寸和材料类型，再按批次找数据，不按 Epson／Nikon 等扫描仪品牌选择文件。
4. **已有输入 ICC。** 可以登记用户自己生成或厂商提供的 ICC，注明来源和匹配的软件／模式。厂商通用配置是先验；别人的同型号 ICC 不是本机验证。外部软件已转成 sRGB／Adobe RGB 的 TIFF 不能再次按 scanner ICC 解释，否则可能重复转换。

没有靶或批次文件时，登记“参考不足”而非从网上找同型号任意 ICC 宣布完成标定。老旧或褪色靶的出厂数据未必仍代表当前状态，需向供应商核实或重新测量。

## 扫描与拟合的接入路线

记录扫描软件与版本、透射／反射、分辨率、曝光／模拟增益、位深和已开启的图像处理。获取色靶图像时使用已明确的未反相输入设置，避免自动端点、锐化和创作调整进入测量；驱动不能关闭的处理需原样记录并限定 profile 的使用条件。

当前模块仅保存配置与材料。后续 ICC 路线可对接用户已安装的工具，参考 [ArgyllCMS 官方扫描仪示例](https://www.argyllcms.com/doc/Scenarios.html)：图像、布局模板、测量参考经过 `scanin` 提取，再由 `colprof` 建立输入 ICC。布局模板描述色块位置，参考数据描述测量值，两者不能互相替代。第一版不自动安装／执行外部工具，不把文件存在检查包装成拟合成功。

用于反射／正片的常规 IT8 ICC 与彩色负片染料域不同。SilverFast 的 [IT8 手册](https://www.silverfast.com/download/docu/ch7.02it8-calibration_en_2006-06-19.pdf)明确其该流程面向反射和透射正片，不适用于负片原稿。因此我们先保存输入表征与适用范围，负片密度与卷级响应继续独立处理；不将其标记为 Status M 或场景重建已完成。

## 模块下一批实现的判据

相机：原 CFA 与参考读取契约、扣黑所有权测试、条件匹配，再实现 dark/open。扫描仪：先识别参考域和导出设置，再支持色靶数据解析／布局取样和已生成 ICC 的验证接入。两路均需独立验证数据及可追踪的应用状态，才开放“应用到胶卷”。
