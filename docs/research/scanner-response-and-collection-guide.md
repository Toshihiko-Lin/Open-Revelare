# 扫描仪密度响应拟合与素材采集引导

日期：2026-11-18。已实现首版扫描测量读取、逐通道密度响应拟合、独立扫描验证、模型／报告导出与应用内素材引导。不改普通导入、反转或既有胶卷；尚未完成真实扫描设备精度验证。

入口调整：标准用户优先沿用 SilverFast／VueScan／ArgyllCMS 的参考或输入 ICC，见 [标准接入与相机操作引导](standard-scanner-assets-and-camera-instructions.md)。本文的 JSON 密度拟合已移入高级折叠区，不再作为所有扫描仪用户的必经步骤。

## 1. 用户入口

“设置 → 设备校准…”中：

- “素材采集引导…”根据采集类型显示相机五步或扫描仪六步流程，解释参考角色、拍摄／扫描设置、不能替代的材料和结果边界。
- 相机继续使用一张暗场、一张无片场和同条件 Bayer RAW 试算；引导明确未曝光片基不是无片场，保存参考不表示校准通过。
- 扫描仪提供“导出扫描参考模板…”及“拟合扫描仪响应…”，与相机 dark/open 完全分开。

## 2. 扫描参考准备

准备带实测数据与测量条件、能放入片架的透射阶梯／目标。记录目标编号、参考密度定义、测量条件、材料范围与用户允许的最大密度误差；不根据扫描仪型号下载任意通用矩阵，也不把 IT8 的 Lab／XYZ 当作密度值。

固定扫描软件／版本、透射模式、分辨率、曝光与驱动校正状态。保存两次独立扫描为线性设备 TIFF，第一份登记为“色靶图像”，第二份为“独立验证扫描”。不能仅复制文件伪装独立采集；程序检查路径不同，真实独立性仍由用户声明，无法从文件名证明。

使用“导出扫描参考模板…”生成 JSON。模板包含：

- `IsTemplate`：默认 true，必须在填写真实数据后改为 false。
- `IndependentValidationCaptureDeclared`：确认验证图来自独立扫描，默认 false。
- `TargetIdentifier`：应与配置中的色靶批次／编号一致。
- `ReferenceDefinition`、`ReferenceMeasurementConditions`、`MaterialScope`：说明物理参考量、测量条件、材料适用范围。仅填“RGB”不构成可靠的参考定义。
- `MaximumValidationDensityError`：用户根据用途和参考精度设定的最大密度残差，必须大于零；模板中的零值不能直接使用。
- `Patches`：至少三块训练和两块验证。每项有原图像素坐标 `X/Y/Width/Height`、三个 `ReferenceDensity` 和 `Validation`。

`Validation=false` 的 ROI 属于第一张图；true 属于第二张图。同图 ROI 不可重叠，应选色块均匀内区，避开边缘、划痕和缺陷。坐标针对未旋转原图；不同扫描可分别填写坐标。当前通过编辑 JSON 指定区域，尚无图形化框选。

将完成的文件登记为“色靶参考数据”。配置选择扫描仪、透射、线性设备通道和指定参考密度，填写软件、导出设置、驱动扣黑与空间／白校准状态，再运行拟合。结果不写回原图。

## 3. 独立数值读取

`TiffIO.LoadScannerMeasurementTiff` 读取顶左方向、CONTIG RGB、非平铺的 16-bit 无符号或 32-bit 浮点 TIFF。保留设备通道、复制／归一化码值，不经过既有 ResolveIcc、CMM、TRC、黑电平或图像内容归一化。源量化步距保留在 ImageBuffer 中。

首版拒绝带 ICC／TransferFunction 的文件，不是建议用户剥掉处理后文件的标签。请从扫描软件重新导出设备数据；没有这些标签也不证明文件一定线性，因此输入状态和上游处理还需来源记录及后续实测验证。其他容器、扫描仪 DNG、灰度和 RGBI 当前不由此入口处理。

## 4. 拟合与模型应用

每块先在原线性设备通道求均值，再取 `x=-log10(mean)`。非有限／非正值不以 epsilon 修补；整数输出码到达 1 的参考区域会被拒绝，以避免用可能截断的端点拟合。浮点扩展正值不因大于 1 自动拒绝。该规则仅针对用户选择的参考区域，不筛选普通负片像素，也不代表完整的传感器饱和检测。

逐通道最小二乘拟合 `D_reference = scale × x + offset`。要求参考跨度非退化、scale 为正且有限；训练和验证最大绝对密度误差均不得超过用户限值，报告分别保存 RMSE 和最大误差。验证输入必须位于训练密度范围内，否则拒绝，不能把外推当作验收。

Core `Apply` 返回明确身份的参考密度数组和逐通道有效标记；范围外、非正或非有限输入不外推、不裁剪，输出 NaN 与 false。不是线性 RGB，后续接入不能再次盲目取 log。GUI 当前只拟合并导出模型／报告，尚不调用 Apply 修改胶卷。

中性阶梯只能支持已声明材料与灰阶响应的结论，不能证明彩色负片的串扰或标准三通道密度已校准。材料与测量定义随模型保存；训练范围内的数值可计算不等于训练外材料有效。两个验证块是最低运行条件，不是充分的实验设计或标准认证。

## 5. 报告与验证

导出的 `openrevelare-scanner-density-fit-v1` 包含配置、参考路径和 SHA-256、参考定义、材料范围、每通道系数、适用输入密度区间、训练／验证数量及误差限／结果。拟合前后核验三份登记参考的摘要。报告含本机路径，导出不打包源文件。

已加入测试：已知比例／偏移恢复、独立验证误差拒绝、退化响应／重复 ROI／范围外验证拒绝、模板和参考定义约束、应用时不外推、原数组不改写、设备 TIFF 码值保留与 ICC 拒绝。实际扫描精度和图形界面操作仍需另外验证。

## 6. 后续边界

后续增加图形化 ROI、更多验证会话与测量报告查看、扫描软件可追踪导出证据、模型的硬件／设置适用性解析，再决定是否开放应用到胶卷。常规 TIFF 导入和已有 ICC 管理保持原路径，不因测量读取的保守限制而拒绝普通图像。
