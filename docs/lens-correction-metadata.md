# 自动镜头校正

新卷导入、追加原片和面板中的自动选择均按帧执行：**有效内嵌曲线 → Lensfun → 不应用**。只有拍摄元数据实际命中时才应用，不凭机身品牌推断支持情况。未标定手写镜头估算表已移除。

## 内嵌基础曲线与手动微调

Sony 读取 MakerNote 和 Exif SubIFD 中的 `0x7037` / `0x7032`，同时接受 SHORT 和 SSHORT。完整保留全部径向样点：畸变使用 `1 + knot/16384` 的分段线性插值，暗角使用 `2^(knot/16384)` 的增益样点插值。不再把整条曲线压缩成一个 k1 或固定范围参数。Sony 标签含义与径向采样位置仍依据贡献者的样片解释，尚缺独立标定验证，不将这些参数称为测量真值。

DNG OpcodeList3 支持 opcode 1 的四项径向加两项切向模型、每平面独立系数、非单位常数项、非居中光学中心，以及 opcode 3 的完整五项暗角多项式。归一化半径取光学中心到最远角的距离。恒等曲线仍是有效内嵌来源，不回退到其它模型。

暗角公式来自 [Adobe DNG SDK](https://android.googlesource.com/platform/external/dng_sdk.git/+/master/source/dng_lens_correction.h)：`gain = 1 + k0*r² + k1*r⁴ + k2*r⁶ + k3*r⁸ + k4*r¹⁰`。所有系数为零意味着恒等增益；不采用“k0 约为 1，所以减 1”的解释。

解析器检查平面数、完整载荷、有限值、中心范围、增益范围及径向导数；超出当前版本能力的必需 opcode 和重复同类 opcode 会导致回退，不能静默覆盖前一条变换。允许跳过标记 optional 的未知 opcode。当前仅处理基础 DNG 1/3 操作，不执行任意 opcode 链。

内嵌基础曲线独立存放于 `FrameParams.EmbeddedLens`。畸变、暗角、范围三个滑块只表示基础校正之后的额外手动微调。LCC 在传感器坐标中优先处理暗角，随后应用内嵌几何校正；不重复应用内嵌或 Lensfun 暗角。Lensfun 与内嵌基础互斥。

## GUI 操作

- 自动选择当前帧／逐帧自动校正整卷：重新选择基础来源，清零该帧的手动微调；整卷操作一次撤销。
- 同步滑块到选中帧／整卷：同步最终微调值，不复制内嵌曲线，也不重新检测其它帧。纯手动微调可在不同基础来源间同步；旧版混合来源的滑块不能再叠加到 Lensfun 或原生曲线上。
- 重置当前帧／整卷滑块：只重置微调，保留原生基础曲线和 LCC。
- 关闭当前帧／整卷自动校正：关闭内嵌基础和 Lensfun，保留新版本的独立手动微调；旧版把内嵌参数填进滑块的工程无法拆分来源，因此旧版混合滑块同时清零。操作可撤销。

界面显示每帧来源与回退原因（未检测到、数据无效或不支持、无法读取）；整卷完成后报告内嵌、Lensfun 和未应用的帧数。内嵌基础仍存在时，手动开启 Lensfun 会提示先关闭自动校正。

曲线、来源、回退原因和微调一起保存进 `.ncproj`。重开工程恢复已保存参数，不重新检测或覆盖微调。旧工程缺少原生曲线时保持旧的数值行为，可通过重新自动选择迁移。

## 一致性与性能

一次元数据读取同时服务内嵌检测和 Lensfun 匹配；共享缓存按源文件路径、长度、最后修改时间区分，容量有界。覆盖源文件会使旧检测结果失效。

全图和区域渲染使用同一校正函数。区域解码使用覆盖全部颜色平面、径向与切向项的保守区间边界，不依赖只采样边缘，也不无条件解码全图。自动选择先准备全部结果，再一次发布；切帧、换卷、编辑或源文件丢失时不部分应用。

回归测试包括 Nikon 样例形状的非单位常数项、不同平面、偏移中心、切向项、独立公式核对、合成平场恢复、区域与全图一致性、LCC 去重、工程保存、深拷贝、缓存失效以及基础开关与撤销。真实 ARW 回归仍由 `OPENREVELARE_LENS_SAMPLES` 提供本地样片；未配置时不代表执行了真实样片验证。本轮未独立复测 issue 作者的真实 ARW/DNG 文件，也未获得跨机型实拍效果的结论。
